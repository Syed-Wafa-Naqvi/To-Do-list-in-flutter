## ⚡ Option 1: 1-Click Startup (Recommended)

- **macOS / Linux**:
  ```bash
  ./run.sh
  ```
- **Windows**:
  Double-click `run.bat` (or run `run.bat` in Command Prompt):
  ```cmd
  run.bat
  ```

*The runner script will verify your Flutter installation, download dependencies via `flutter pub get`, and launch the application immediately.*

## 🛠️ Option 2: Run in VS Code (Visual Studio Code)

1. **Open the project folder** in VS Code:
   `File > Open Folder...` and select this extracted directory.
2. **Install Flutter Extension**:
   If not already installed, install the official **Flutter** extension (by Dart Code) from the Extensions tab (`Ctrl+Shift+X`).
3. **Fetch Dependencies**:
   VS Code will prompt you to run `flutter pub get`, or you can open the integrated terminal (`Ctrl+` `) and run:
   ```bash
   flutter pub get
   ```
4. **Select a Target Device / Browser**:
   Click on the device selector in the bottom-right status bar (choose Chrome, Android Emulator, iOS Simulator, or Desktop).
5. **Launch the App**:
   Press **`F5`** (or go to `Run > Start Debugging`).

---

## 📱 Option 3: Run in Android Studio / IntelliJ

1. Open Android Studio and choose **Open** to select this project directory.
2. If prompted, click **Get dependencies** (or run `flutter pub get` in the built-in terminal).
3. Select your desired emulator or connected device from the device dropdown at the top.
4. Click the green **Play (▶)** button to launch.

---

## 💻 Option 4: Manual Terminal Run (Step-by-Step)

1. **Ensure Flutter is installed**:
   ```bash
   flutter doctor
   ```
2. **Install dependencies**:
   ```bash
   flutter pub get
   ```
3. **Run automated test suite**:
   ```bash
   flutter test
   ```
4. **Launch the application**:
   - To run on your default connected device / emulator:
     ```bash
     flutter run
     ```
   - To run directly in your web browser (Chrome):
     ```bash
     flutter run -d chrome
     ```

## ❓ Troubleshooting

- **"flutter: command not found"**:
  Make sure the Flutter SDK is installed and added to your system's PATH. See [Flutter Installation Guide](https://flutter.dev/docs/get-started/install).
- **"No connected devices found"**:
  Run `flutter run -d chrome` to launch the app inside Google Chrome without needing a mobile emulator.
